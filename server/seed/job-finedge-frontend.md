Senior Frontend Engineer (React) - FinEdge Technologies

Location: Karachi, Pakistan (hybrid, 2 days on-site) or remote within Pakistan
Employment type: Full-time

About FinEdge Technologies
FinEdge Technologies is a Karachi-based fintech company building real-time payment and ledger tooling for regional banks and financial institutions. Our engineering team is remote-first across Pakistan, with a small hybrid hub in Karachi. We ship fast, review carefully, and measure everything.

The role
We are hiring a Senior Frontend Engineer to own our customer-facing dashboard suite: real-time settlement views, transaction search, and admin tooling used by partner banks. You will work in TypeScript across a React and Next.js codebase, partner with backend engineers on API contracts, and raise the bar on frontend quality, performance, and testing.

- Strong TypeScript and modern JavaScript (ES2020+)
- Production experience with Next.js, including SSR/SSG and routing
- State management at scale (Redux, Zustand, or similar)
- Styling systems: Tailwind CSS or CSS-in-JS
- Consuming and shaping REST APIs; familiarity with GraphQL is a plus
- Testing discipline: unit and integration tests (Jest, React Testing Library, Playwright or Cypress)
- CI/CD familiarity (GitHub Actions) and Docker basics
- Strong communication skills; comfortable in a remote-first team
- Based in Pakistan; Karachi or remote
